# Super-G - Kitboga Codejam 26 Entry
This simple ad overlay is my first attempt at creating some pixel art animations :)
It's a simple goose that gets agitated if you move your mouse too fast and runs away with your skip ad button.
To defeat it you have to be very fast or very slow to not agitate the goose.
